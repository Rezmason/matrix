# Matrix Digital Rain Effect

This is a single self-contained offline-capable HTML file version of the Matrix digital rain effect.

## Key Differences:
- **Self-Contained**: This version can be run directly from your local machine without any dependencies on a web server, making it easy to use anywhere.
- **Full Version**: In contrast, the full version on the master branch requires a web server to function correctly, as it relies on additional resources and possibly external assets.

Enjoy the digital rain effect directly in your browser with this simplified implementation!
